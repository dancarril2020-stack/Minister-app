## Requirements

### Requirement: Global Navigation Structure
The PWA SHALL provide persistent top and bottom navigation bars across primary views.

#### Scenario: Mobile view bottom navigation
- **WHEN** user is on a mobile viewport
- **THEN** system displays the bottom navigation bar with icons for Dashboard, Formation, Map, and Menu

#### Scenario: Top navigation contextual actions
- **WHEN** user navigates to a specific view
- **THEN** top navigation displays the view title and relevant contextual actions (e.g., Back button, Profile icon)

## MODIFIED Requirements

### Requirement: Dashboard Overview Metrics
#### Scenario: Viewing the 4 core metric cards
- **WHEN** the user views the general summary dashboard
- **THEN** the system displays 4 specific metric cards: Active Partnerships, Assigned Families, Unvisited Families, and Zones.

### Requirement: Dashboard Display
#### Scenario: Viewing the main screen header
- **WHEN** the user views the main screen
- **THEN** the system does not display the redundant word "Dashboard" in the header text.

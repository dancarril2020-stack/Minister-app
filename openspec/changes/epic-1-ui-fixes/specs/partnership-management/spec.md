## MODIFIED Requirements

### Requirement: Partnership Card Layout
#### Scenario: Viewing companion avatars
- **WHEN** the user views the partnership list
- **THEN** the system displays overlapping avatar icons to the left of the companions' names.

#### Scenario: Viewing zone tags
- **WHEN** the user views the partnership list
- **THEN** the system displays zone name tags color-coded according to the specific zone.

#### Scenario: Formación navigation
- **WHEN** the user views the partnership list
- **THEN** the system displays a "Formación" navigation button alongside the existing floating elements, and the bottom margin is sufficient to prevent the floating menu from hiding the last card.

### Requirement: Partnership Detail Checklist
#### Scenario: Viewing family specific checklist
- **WHEN** the user opens a partnership detail view for a family
- **THEN** the system displays the family's avatar and address.
- **AND** the system displays exactly four specific checklist items: Lectura de Escrituras, Oración, Noche de Hogar, y Asistencia al Templo.
- **AND** the system displays a family-specific notes section.

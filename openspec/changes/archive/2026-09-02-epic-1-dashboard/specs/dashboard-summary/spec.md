## ADDED Requirements

### Requirement: General Summary Metrics
The Dashboard SHALL display aggregated metrics for ministering efforts.

#### Scenario: Viewing active metrics
- **WHEN** user loads the General Summary view
- **THEN** system displays cards showing total partnerships, pending visits, and urgent alerts

### Requirement: Urgent Attentions List
The Dashboard SHALL present a list of urgent attention items requiring immediate action.

#### Scenario: Viewing urgent attentions
- **WHEN** there are urgent items flagged
- **THEN** system displays them prominently on the dashboard with a call-to-action button

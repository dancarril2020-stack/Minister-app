## Why

We need a central hub for administrators to track ministering efforts, view urgent alerts, and manage partnerships. Epic 1 establishes the foundational user interface components and core dashboard views to make the application immediately useful for managers.

## What Changes

- Create the base application layout including the top and bottom navigation bars.
- Build the "General Summary" dashboard featuring metric cards and alerts for pending visits.
- Develop the Partnership Board (Tablero de Compañerismos) with progress tracking and zone filters.
- Implement the Partnership Detail view with an interactive checklist.
- Add the Formation View, which provides an interactive visual org chart.

## Capabilities

### New Capabilities
- `base-navigation`: Top and bottom navigation bars for the PWA structure.
- `dashboard-summary`: Displays key metrics, alerts, and urgent attentions.
- `partnership-management`: Lists, filters, and displays detailed interactive checklists for ministering partnerships.
- `formation-view`: Visual interactive organization chart.

### Modified Capabilities
None

## Impact

- Scaffolds the primary route structure in the React frontend.
- Introduces foundational UI components (cards, lists, interactive charts) into the design system.
